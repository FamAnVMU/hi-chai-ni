# Hi Chinese - AI-Powered Personal Chinese Learning (Flutter Native Android)

Ứng dụng học tiếng Trung AI thông minh dành riêng cho Android, xây dựng 100% bằng Flutter Native.

## 🚀 Đặc Điểm Cốt Lõi (100% Mobile Standalone)
* **Không phụ thuộc máy tính:** Chạy hoàn toàn độc lập trên thiết bị Android, không cần server trung gian.
* **Offline-First:** Cơ sở dữ liệu SQLite cục bộ (`sqflite`), học từ vựng, ngữ pháp, flashcard SRS không cần internet.
* **Trí tuệ nhân tạo Gemini AI:** Tích hợp trực tiếp Google Gemini API SDK (`google_generative_ai`), AI Tutor đồng hành 24/7.
* **Native Audio & UI 120fps:** Tối ưu hóa hoàn toàn cho màn hình cảm ứng Android, tự động tương thích tai thỏ và thanh điều hướng ảo.
